# Memory – uputstva za goste i Wellness 1.2.2

[Preuzmi kompletan WordPress plugin (ZIP)](https://github.com/vikipejic110-bot/test-memory/raw/refs/heads/delivery/memory-wellness-1.2.2-20261107/Memory-Wellness-1.2.2.zip)

Kompletna verzija postojećeg plugina, sa svim prethodnim funkcijama:

- Digitalna uputstva, postojeći linkovi i QR kodovi, apartmani i obavještenja.
- Rezervacije saune, odobravanje i odbijanje zahtjeva, upravljanje terminima i zaštita od duplih rezervacija.
- Prikaz datuma u formatu dan.mjesec.godina.
- Broj zahtjeva na čekanju uz Wellness, koji se osvježava bez ponovnog učitavanja stranice.
- Ime gosta iz rezervacije automatski se predlaže u formi za saunu; gost ga može promijeniti bez mijenjanja originalne rezervacije.

## Nadogradnja

1. Sačuvajte rezervnu kopiju baze i postojeće verzije plugina.
2. U WordPressu otvorite **Dodaci/Plugini → Dodaj novi → Otpremi dodatak** i izaberite ZIP.
3. Kada WordPress prepozna postojeći plugin, izaberite **Zamijeni trenutni dodatak otpremljenim**.
4. Provjerite postojeći link za gosta i Wellness panel.

Nemojte prethodno brisati postojeći plugin. Ako instalacija vrati 403, zamijenite datoteke postojećeg direktorija `wp-content/plugins/memory-guest-guide/` kroz hosting File Manager ili zatražite zamjenu od podrške hostinga. Ne mijenjajte bazu niti WordPress ključeve.

Nadogradnja je lokalno testirana uz očuvanje postojećih zapisa, tokena, podešavanja i rezervacija. Produkcijski sajt nije mijenjan u okviru pripreme ovog ZIP-a.
