MEMORY REZERVISI V2 – ZAMJENA POSTOJEĆEG ISJEČKA

1. Raspakujte ZIP.
2. WordPress → Snippets → Import.
3. U odjeljku Duplicate snippets izaberite DRUGU opciju:
   Replace any existing snippets with a newly imported snippet of the same name.
4. Izaberite Memory-Rezervisi-ikonice-cijene-V2.json i Upload files.
5. Označite jedini ponuđeni isječak i kliknite Import Selected (1).
6. U All Snippets provjerite da je isječak aktivan (plavi prekidač).
7. Otvorite Rezerviši i osvježite Ctrl+F5. Očistite keš ako je uključen.

Naziv isječka ostaje isti da bi se zamijenio postojeći. Ne pravite dva aktivna primjerka istog isječka.

Dodatak Ikonice apartmana i ostale isječke ostavite aktivnim. ZIP se raspakuje; JSON se uvozi u Code Snippets.

V2 prepoznaje svih 11 naziva iz dostavljenog stvarnog prikaza, uključujući FAMILY LUX i SPA LUX APT-ROYAL. Koristi podatke iz postojećeg dodatka Ikonice apartmana. Ikonice su manje i u jednom redu. Izvorne crne ikonice kapaciteta se skrivaju samo gdje su zamijenjene podacima apartmana.

Precrtavanje primjenjuje na WebBookingPro strike/s/del element sa prethodnom cijenom, uz provjeru niže trenutne cijene i iste valute. Ne mijenja iznose, rezervacije, kapacitet rezervisanja niti bazu.

Provjereno u Chromiumu na dostavljenom HTML prikazu: 11 apartmana, 14 precrtanih prethodnih cijena, uklonjene duple ikonice, jedan red na 1440/390/360 px. Provjereni su i promjena sadržaja, nepoznati nazivi, regularne cijene i završni korak na izolovanom modelu aplikacije. Nije izvršena rezervacija ni izmjena produkcijskog sajta.


Prethodni linkovi za plugin Uputstva za goste / Wellness ostaju važeći. Ovaj paket mijenja isključivo postojeći prikaz rezervacija kroz Code Snippets.
