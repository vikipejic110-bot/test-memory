# Memory – uputstva za goste i Wellness 1.2.3

Naziv usluge je svuda u prikazu za gosta i administratorskom panelu usklađen na **Wellness**. Naslov kod gosta je **Rezerviši Wellness**, odnosno **Book Wellness** na engleskom. Usklađene su i poruke, podešavanja i opis oznake zahtjeva na čekanju.

Ova verzija mijenja samo tekstove i oznaku verzije. Postojeći linkovi, QR kodovi, podešavanja, rezervacije i način rada ostaju isti. Svih 26 datoteka kompletnog plugina je uključeno; ostale funkcionalnosti prethodnih verzija su zadržane.

## Nadogradnja

1. Sačuvajte rezervnu kopiju baze i postojeće verzije plugina.
2. U WordPressu otvorite **Dodaci/Plugini → Dodaj novi → Otpremi dodatak** i izaberite ZIP bez raspakivanja.
3. Kada WordPress prepozna postojeći plugin, izaberite **Zamijeni trenutni dodatak otpremljenim**.
4. Provjerite postojeći link za gosta i Wellness panel.

Nemojte prethodno brisati postojeći plugin. Ako instalacija vrati 403, zamijenite datoteke postojećeg direktorija `wp-content/plugins/memory-guest-guide/` kroz hosting File Manager ili zatražite zamjenu od podrške hostinga. Ne mijenjajte bazu niti WordPress ključeve.

Provjereni su PHP sintaksa, sadržaj ZIP-a i obim promjena: samo tekstovi, komentar, dokumentacija i verzija. Ostale 22 datoteke su identične verziji 1.2.2. Nema migracije podataka. Produkcijski sajt nije mijenjan prilikom pripreme ZIP-a.
